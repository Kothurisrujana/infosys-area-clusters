# Infosys Area Price Clusters

A map of the areas within 9 km of Infosys, Gachibowli, Hyderabad. Upload property files (CSV or Excel) for each area to see its border, grid cells, project dots and buyer-fit classes.

- **Open it:** `website/index.html`. It needs no build step or server, only internet for the map and libraries.
- **Your files stay in your browser:** uploads are not sent anywhere, and each visitor sees only their own. Property files are not stored in this repository.
- **File columns:** a price column (`price_numeric` or `asking price`) is required. `lat-lon`, `area_sqft`, `bhk`, `status` and `name of the project` are used when present.

Map data © OpenStreetMap contributors.
